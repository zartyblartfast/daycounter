Scheduled Backups

Automate server-stored backups using cron on your VM. The app provides a token-protected endpoint that cron calls to trigger a backup with automatic retention pruning.

Setup steps:
  1. Add a secret token to your .env file: 
    BACKUP_CRON_TOKEN=your-secret-token-here
  2. Restart the app to pick up the new token.
  3. Add a cron entry on the VM (crontab -e): 
    # Daily backup at 02:00
0 2 * * * curl -sf "http://localhost:8000/backup/cron?token=your-secret-token-here" >> /var/log/daytracker-backup.log 2>&1
Common schedules:
FrequencyCron expression
Every 6 hours0 */6 * * *

Backup Contents

Each backup zip contains:

  • data/daytracker.db — Complete SQLite database (travel records, settings, evidence metadata)
  • vault/ — All uploaded evidence files (boarding passes, receipts, etc.)
  • manifest.json — Backup metadata (timestamp, version, file inventory) for verification

Recovery workflow: Download the .zip → copy to cloud storage (OneDrive, Google Drive, etc.) → on a new deployment, upload via the Restore panel above.
